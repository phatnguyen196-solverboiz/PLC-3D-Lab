PLC 3D LAB - Mo phong bang tai va Ladder

Cach chay tren may:
1. Giai nen file ZIP.
2. Trong thu muc chua index.html, mo terminal va chay: python -m http.server 8000
3. Mo trinh duyet tai http://localhost:8000

Web gom mo hinh 3D xoay/zoom, so do chuc nang 24 V, bang I/O, rung Ladder co the them/sua, timer TON, counter CTU, mo phong scan 100 ms. Dung nut Luu JSON/Mo JSON de giu chuong trinh.

Day la mo phong hoc tap, khong duoc dung truc tiep lam so do dau noi may that. E-stop tren may that can mach an toan phan cung doc lap PLC.
